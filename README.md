# genesis

Библиотека для определения оптимального размещения пожарных подразделений с учетом различных подходов

Основная папка проекта - `work`. В ней хранятся одновременно файлы документации, карта (`*.qgs, /data, /fire_data`), папка с самой библиотекой (`work/genesis`).

Работу организовываем примерно так -- пишем библиотеку, тут же ее можно документировать, ссылаясь прямо из документации. Кроме того, сразу получается готовая карта.
