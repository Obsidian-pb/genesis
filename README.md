# Genesis

Библиотека пространственной оптимизации размещения подразделений пожарной охраны на основе эвристических алгоритмов и их гибридов.

## Модули

| Пакет | Назначение |
|-------|------------|
| `genesis` | Ядро: базовые классы алгоритмов (MCLP, LSCP, выбор точек, метрики) |
| `graphs` | Операции с графами УДС (скорости, алгоритмы, настройки) |
| `fire_units` | Надстройка для расчётов пожарных подразделений (состояния, метрики, MCLP) |
| `lists` | Справочники и наборы данных (здания, участки, КФПО) |

## Основные зависимости

Python ≥ 3.9, numpy, pandas, networkx, geopandas, shapely, osmnx

## Структура репозитория

```
work/genesis/       — исходный код библиотеки, тесты, данные
work/docs/          — документация (*временно в дальнейшем будет удалено*)
archives/           — архивные материалы
genesis_env.yaml    — conda-окружение
```
